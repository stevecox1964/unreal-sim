**Diagnosis (facts from code + DB):**
1. A place = anchor point + fixed 900 cm box (`PLACE_EXTENT_CM`). The anchor is where the APC
   stood when it named the place — on the street. `route_planner.at_place` counts arrival anywhere
   in that box, so "arrived" = sidewalk.
2. `owned_place_cells` is keyed `(col, row, owner, name)` with `dx/dy` offset from the grid-cell
   center. A place belongs to exactly one 30 m grid cell; buildings cannot straddle grid lines.
3. Don's Donuts is duplicated: `(7,5) maren "Don's Donuts"`, `(7,5) dufus "Don's Donuts"` (anchors
   ~9 m apart), `(6,6) dufus "Don's Donuts town square"`, plus grid name `(7,5) "Don's Donuts
   building with large donut sign"`.
4. Survey treats interiors as off-limits: grid `(6,4)` is named `"purple-walled kitchen (indoors,
   not survey ground)"`. `perception.py` has a `building_interior` footing label.

## Decisions locked in this session

- Grid cells (30 m) stay as a map/survey **index only**; they no longer own places.
- A place is built from **3 m tiles** (30 m grid cell = exactly 10×10 tiles, so they align).
  A place may span grid cells. Default new place = 3×3 tiles (9 m), matching old size.
- One real-world place = one row (Don's Donuts becomes one shared place); `owner` stays for
  personal places (homes, Maren's truck).
- Places grow from **body facts**: tiles an APC actually stands on inside the place get added
  (lizard-brain contract; body writes, LLM doesn't). Landmark_BP actors seed the first tile.
- New action "investigate place": walk to it, find the entrance, go in, look around; place grows.
- Arrival = standing on the place's tiles, not near an anchor.
- Survey allows interiors (drop the "not survey ground" treatment).
- Migration: merge duplicates by name; old 9 m boxes → 3×3 tiles.
- Speed mode: no tests (test ideas → backlog ledger). Don't push until user says "push".

## Open questions

- How to merge Maren's vs Dufus's Don's Donuts anchors (~9 m apart) — proposal: union their tiles.
