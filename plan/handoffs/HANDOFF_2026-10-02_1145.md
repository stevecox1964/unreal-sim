## What was done this session

- **`tools/run_debugger/`**: its own uv project on Python 3.14, with Manim Community v0.21.0.
  Usage and details are in `tools/run_debugger/README.md`.
  - `analyze.py`: reads `agent_decisions.log`, `sim_runner.log`, and `api_calls/SR<n>.jsonl`.
    Writes `out/<run>.json`. It flags each decide call as **retry**, **redundant** (same
    action + intent + cell, or ≥85% similar thought), or **loop** (back to a cell left within
    6 calls). It rebuilds look → think → act timing backward from each row's timestamp.
  - `page.html` (template) + `render.py`: write `run_analysis/SR<n>_<YYYYMMDD_HHMMSS>.html`.
    The page has real-time lanes per APC with icons, a minimap, play at 1–60×, a scrub bar,
    "stop at flagged calls", ←/→ to jump between flags, a click-for-details panel, an
    "at the playhead" panel, a feed, wheel zoom, drag pan, and an API lane.
  - `replay.py`: Manim scene. It runs via `render.py SR45 --video [l|m|h]`.
    The user found the video too fast to read, so HTML is now the default.
- **`Python/agent_runtime/api_call_log.py`** (new): `track(purpose, agent, provider, model)`
  context manager, plus `note_usage()` (tokens via a contextvar) and `for_agent()` (names the
  agent for vision calls). Writes one file per run and keeps the newest `KEEP_RUNS = 50`.
  - Hooked into `llm_router.py`: orient = `wake`, `decide`, `ask`, and `chat`, plus token
    reads for Anthropic, OpenRouter, and OpenAI.
  - Hooked into `perception.py` (`vision`), with token reads.
  - Hooked into `ollama_adapter.py` (tokens).
  - In `agent_manager.py`, `_attach_run_log` calls `set_dir`. The 3 `perceive()` call sites
    are wrapped in `for_agent`.
- **Measured on SR45:** 93 decide calls and 947 s of model time; 520 s (55%) went to flagged
  calls. Maren had 26 retries.
- `plan/backlog.md`: new item **#112**, with its "needs a test" notes.

## Decisions locked in this session

- **The HTML page is the default; the video is an extra (`--video`).** Why: the user could not
  read a video that "blasts by"; scrubbing fixes that.
- **The page is a standalone file, not a cockpit page (for now).** Why: it is fast, needs no
  server, and each file stands alone. Moving it into the cockpit (`/api/replay`, #14) is a later
  option.
- **One API log file per run, keep the newest 50.** Why: one file per run keeps the analyzer
  fast and makes cleanup one delete. Size was never the real risk: about 2–5 MB per overnight
  run.
- **Run names stay `SR<n>`.** The date-style name in the user's first example
  (`2026-10-02-0017`) does not exist in the logs. A date → SR lookup was offered and not taken
  up.
- **Speed mode:** no tests were written. Test ideas are recorded in backlog #112.
